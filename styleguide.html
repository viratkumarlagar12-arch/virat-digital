Style guide

The tokens and components behind the Virat Digital site. Build new sections from these instead of adding new colours, sizes or one-off styles. The palette and contrast tables are read from the live CSS, so they stay accurate when a token changes.

Ink & Marigold

Virat means immense. The system takes that literally: headlines are set wide and large on Archivo's width axis, and everything around them stays quiet. Deep indigo ink is the ground. Marigold, the colour of festival garlands and of the thumbnails clients want clicked, marks what you can act on.

  • Type is the visual

    Headlines run expanded at large sizes and widen as the screen grows. No glow blobs, orbits or stock art compete with them. The one animation on the site is the hero headline widening into place.

  • One accent, used for action

    Marigold fills primary buttons, the current nav item, active process steps and the closing call to action. It never decorates, so it always means "this is the thing to do".

  • Structure carries meaning

    Numbers appear only on the four-step process, because it is a sequence. No all-caps labels above headings, no glowing dots, no centred section heads.

  • Both themes, equal care

    Dark is the brand default; light follows the visitor's device setting or the toggle. Every text colour passes WCAG AA in both, as the table below shows.

Foundations

Three layers. Primitives hold raw values, semantic tokens name a role and switch per theme, and each component builds its own local props from the semantic layer only. All of it lives in css/tokens.css.

Colour

Ink is a neutral tinted toward indigo, so greys never look unconsidered. Marigold is the only accent hue.

        Rules for new work

        • Semantic tokens only

          Components use --text, --surface, --accent and friends, never primitives or hex values. That is what makes both themes work.

        • New colour, both themes

          Add the primitive, then the semantic token in the dark block and both light blocks of tokens.css. Check this page's contrast table afterwards.

        • One primary per view

          Marigold fills mean "the thing to do". Supporting actions use outline or ghost buttons.

        • Numbers mean order

          Use .steps only for real sequences. Everything else is a feature list or cards, without numbers.

        • Sentence case, no labels above headings

          Headings stand on their own. No all-caps eyebrows, no decorative dots.

        • Motion answers the visitor

          Hover, press and open states only. The hero headline is the single page-load animation.
